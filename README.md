# GitHub Repository Explorer

A React-based web application that allows users to search, explore, and analyze GitHub repositories using the GitHub REST API.

## Features

- Search GitHub repositories
- Display repository information
- Repository pagination
- Sort repositories by:
  - Best Match
  - Stars
  - Forks
  - Help Wanted Issues
  - Recently Updated
- View detailed repository information
- Display stars, forks, issues, and language
- Display repository topics
- Display language usage
- View top contributors
- Fetch and display repository README
- Display repository license
- Display repository homepage
- Direct link to the repository on GitHub
- Loading and error handling
- Responsive design for smaller screens

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- GitHub REST API
